**Overview**<br>
Fake News Detection is a machine learning project designed to classify news articles as Fake or Real based on their textual content. The project applies Natural Language Processing (NLP) techniques to preprocess news text, extract meaningful features, and train machine learning models for binary classification. The goal is to build a system that can help identify potentially misleading or fabricated news content.<br>
**Dataset**<br>
The project uses a labeled news dataset containing news articles along with their corresponding labels.
The dataset consists primarily of:
News text/title: Content of the news article.
Label: Indicates whether the news is Fake or Real.<br>
**Methodology**<br>
The project follows the following pipeline:
<br>
News Dataset->
Data Cleaning->
Text Preprocessing->
Feature Extraction->
Train-Test Split->
Model Training->
Model Evaluation->
Fake / Real Prediction<br>
**Models Used**<br>
Logistic Regression
Naive Bayes
Support Vector Machine (SVM)
Random Forest
LSTM
